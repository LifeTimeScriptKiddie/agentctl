# Rubric

A passing document must:

1. Contain a `## Overview` heading with a correct 2–3 sentence description.
2. Contain a `## Examples` heading.
3. Include at least two concrete `agentctl` command examples.
4. Be under 200 words and contain no `TODO`/`FIXME` placeholders.

Score 1.0 when all four hold; deduct 0.25 per unmet item.
